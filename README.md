# StudyHub

StudyHub is a campus study-group finder for university students. Students browse the courses offered each semester, find study groups that meet for those courses, and join a group that fits their schedule. Any student can create a group for a course they are taking and act as its leader, managing membership, posting announcements, and keeping the meeting time and location up to date. The goal is to make it easy for students to find classmates to study with instead of relying on word of mouth.

## Project structure

- `code/` – application source code (Maven Java project)
- `documentation/` – project documentation, including the product backlog
