# StudyHub Project Site — Lab 5

A Node.js, Express, and EJS documentation website for the StudyHub
JavaFX application.

## Run the website

Prerequisites: Node.js and npm.
Tested with Node.js 24.13.0 and npm 11.14.0.

From this project-site folder, run:

    npm install
    node app.js

Open http://localhost:8080 in your browser.
Press Control+C in Terminal to stop the server.

## Pages

- / — Project landing page
- /documentation — Documentation index
- /quickstart — Launching the StudyHub Java application
- /features/browse-courses
- /features/browse-groups
- /features/view-details
- /features/search
- /features/create-group
- /features/delete-group

Screenshots are stored in public/images.
Shared page elements are in views/partials.
Styles are in public/styles.css.
